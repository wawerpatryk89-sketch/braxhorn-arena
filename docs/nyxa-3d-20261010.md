# Nyxa 3D trial

User-approved Meshy GLB: Emerald Minotaur Fitn, all animations. Existing sprite Nyxa remains selectable using the NYXA version button on the roster. New 3D is the default for this test site; both player and CPU use the selected version, including mirrors.

The model is preserved byte-for-byte across five static chunks. Textures and original material are retained. Three.js 0.186.1 is vendored with its license. Horizontal hip motion is removed at runtime so gameplay controls arena position. Camera faces the model side-on. Animation samples run at 30 fps. Projected hand/foot bones determine attack boxes near forward extension peaks. This is a first-pass contact calibration, not a manual review of every Meshy strike. Combo chains Punch_Combo_1, Roundhouse_Kick, Sweeping_Kick with 120 ms blended boundaries.

Validation: existing npm test passes. Node GLTF parsing validates 24 mapped actions, finite projected bounds and hit windows. Engine harness verifies seven 3D actions finish and jab contact works in both directions. WebGL drawing and phone performance have not been visually verified: browser QA capability unavailable. User playtesting must check orientation, lighting, transitions and contact accuracy.

No changes to the main separate game or roster artwork.

## Tempo revision
User found the first 3D version too slow. 3D attacks/combo now play at 1.45x, walk movement and gait are 20% faster, hit reaction at 1.65x, jump at 1.25x, other actions at 1.15x. Original sprites retain their tempo. Browser reached the deployed roster, but its WebGL renderer is disabled and throws Error creating WebGL context. Thus visual movement QA remains blocked; local preview also fails with bwrap proc mount permission error. No claim of visually passing 3D QA.

## User decision: replacement
Nyxa 3D is now the only runtime Nyxa. Removed version toggle, GIF data download and legacy fallback. Both player and opponent use the new model.
