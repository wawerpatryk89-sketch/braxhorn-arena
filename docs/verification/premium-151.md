# Consistent fighter cards

All eight fighter cards now share one metal frame drawn as SVG, with a lime selection highlight for both player and opponent. The same artwork and frame are used by the swipe carousels in local play and multiplayer. The VS presentation also uses the unframed artwork. Names and statistics remain real interface text.

The two 1024×1536 WebP atlases contain four portraits each, laid out in a 2×2 grid. They were generated by editing the existing fighter references to remove printed frames, labels and statistics while preserving the characters and costumes. The runtime selects a quadrant with an SVG viewBox; original game models and combat configuration are preserved. The two atlases total approximately 731 KiB. Hidden legacy portrait images now load lazily.

Validation: production build with both new atlases retained; shared UI audit; touch browser checks at 844×390 and 915×412 covering decoded artwork, all eight live frames, actual swipes, statistics, player/opponent confirmation, multiplayer entry and swipe, tournament form layout and VS coverage until fade. An eight-card comparison screenshot was inspected for a consistent frame and illustration style. These are browser simulations, not physical phone performance measurements. The previously verified network timing and combat behavior from release 150 are preserved.
